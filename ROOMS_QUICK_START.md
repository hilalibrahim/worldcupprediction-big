# 🏠 Room Predictions - Quick Start

**Status**: ✅ **READY TO USE**

---

## Access Room Predictions

### 1. Create or Join Room
```
Dashboard → Rooms → Create/Join
OR
http://localhost/worldcupprediction-big/rooms
```

### 2. View Room
```
Click room name to view
OR
http://localhost/worldcupprediction-big/rooms/view/[id]
```

### 3. See Three Sections
```
LEFT:   Room Leaderboard (points ranking)
CENTER: Make Predictions (prediction forms)
RIGHT:  Room Members (predictions count)
```

---

## Make a Prediction

### Quick Steps
1. **Enter Score**: Type 2 - 1
2. **Select Winner**: Pick Home / Draw / Away
3. **Click**: "Submit Both"
4. **Done!**: See "✓ Your Predictions"

### Form Layout
```
🎯 Exact Score (10pts)
[2] - [1]

👑 Who Wins? (5pts)
○ Home   ○ Draw   ○ Away

[Submit Both]
```

---

## See Your Predictions

### After Submit
```
✓ Your Predictions

Score: 2 - 1
Winner: Home Team
```

### After Match Plays
```
✓ Your Predictions

Score: 2 - 1
Winner: Home Team

+10 pts ← Points earned!
```

---

## Points You Can Earn

| Scenario | Points |
|----------|--------|
| Both correct (score + winner) | **10 pts** |
| Only winner correct | **5 pts** |
| Neither correct | **0 pts** |

## Room Leaderboard

### Shows
- Your rank in room
- Points compared to others
- Updates after each match

### Example
```
1. You      - 25 pts ⭐
2. John     - 20 pts
3. Alice    - 15 pts
```

---

## Important Rules

✅ **One prediction per match** (can't change)  
✅ **Predict by 5 min cutoff** (before match)  
✅ **Both score AND winner** required  
✅ **Points earned after match** completes  
✅ **Room points = Global points** (same system)

---

## Cutoff Logic

```
Match: 20:30 IST
Cutoff: 20:25 IST (5 min before)

20:00 → Submit ✓
20:24 → Submit ✓
20:25 → Locked 🔒
```

---

## Status Indicators

| Status | Meaning |
|--------|---------|
| **Open** | Can predict ✓ |
| **Locked** | 5 min cutoff reached 🔒 |
| **✓ Predicted** | Already submitted |
